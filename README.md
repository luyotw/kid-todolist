# kid-todolist

小孩每日任務打勾清單。家長自訂任務，小孩完成就打勾，全部完成有獎勵。

## 開發

```bash
npm install
npm run dev
```

## 技術棧

- Vite + React + TypeScript
- Tailwind CSS
- localStorage（v1 不需要後端）
- PWA（可加到手機主畫面）

## 手機驗收

真機檢查請使用 [docs/mobile-acceptance.md](docs/mobile-acceptance.md)。載入體感：冷啟動與「今日任務 ↔ 設定」切換各試 3 次，應主觀感受為馬上可用。
