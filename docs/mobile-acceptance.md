# 手機體驗手動驗收清單（issue7）

在 **iOS Safari** 與 **Android Chrome** 真機上逐項勾選。發佈前至少各完成一台裝置。

| # | 步驟 | iOS Safari | Android Chrome |
| --- | --- | --- | --- |
| 1 | 直向開啟首頁，確認無橫向捲動 | ☐ | ☐ |
| 2 | 連續打勾 3 項，無誤觸鄰項 | ☐ | ☐ |
| 3 | 切換「今日任務」「設定」Tab，內容正確 | ☐ | ☐ |
| 4 | 確認頂部標題不被瀏海遮住 | ☐ | ☐ |
| 5 | 確認底部 Tab 不被手勢列遮住且可點 | ☐ | ☐ |
| 6 | 使用「加入主畫面」，圖示非破圖 | ☐ | ☐ |
| 7 | 從主畫面圖示開啟，進入可用狀態 | ☐ | ☐ |
| 8 | 冷啟動與分頁切換體感可接受 | ☐ | ☐ |

## 載入體感（主觀）

各平台各試 **3 次**：

1. **冷啟動**：完全關閉分頁或從主畫面圖示開啟，進入後應可馬上看到今日任務（無明顯長時間空白）。
2. **Tab 切換**：「今日任務」↔「設定」來回切換，每次切換應立即顯示對應內容。
